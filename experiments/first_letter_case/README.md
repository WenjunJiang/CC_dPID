# 首字母大小写捷径：原样插入 vs 与标签无关地重抽

`run.sh` → `dPID/tests/first_letter_shortcut.py`。同一模型（新目标函数）、同一数据，只差训练
collator 的 `first_letter_upper_probability`（None = 原样，0.5 = 修复）。

合成数据刻意复现偏差：恶意 payload 95% 小写开头，良性 90% 大写开头；内容信号刻意很弱
（攻击词密度 15% vs 5%），让首字母成为最省力的线索。测试集保持同样偏差；探针把每条测试样本
的 payload 首字母翻转，载体/模板/插入位置完全相同，只差这一个字母。阈值 = 原文良性 1% FPR。

## 结果（3 seeds 均值）

| 指标 | 原样插入 | 重抽大小写 |
|---|---|---|
| 翻转首字母后恶意 margin 平均变化 | **−1.29**（−1.43/−1.38/−1.04） | **+0.12**（−0.38/−0.10/+0.83） |
| 翻转首字母后良性 margin 平均变化 | +0.14 | −0.04 |
| Recall 原文 → 翻转 | 0.24 → **0.12**（减半） | 0.14 → 0.13 |
| PR-AUC 原文 → 翻转 | 0.069 → 0.017 | 0.030 → 0.054 |
| 恶意判定翻转率 | 14.7% | 9.0% |

## 结论

- 捷径真实存在且被学到：原样插入时，只把 `ignore` 改成 `Ignore` 就让 recall 减半。
- 修复后模型对首字母基本不敏感（margin 变化从 −1.29 降到约 0，方向随 seed 不定）。
- 原样插入在"原文"上分数更高，是因为测试集带同样偏差、捷径在这里恰好有效；翻转后它就崩了。
  重抽后的分数才是只靠内容的真实水平。
- 局限：合成内容信号太弱，两臂绝对性能都很低（PR-AUC < 0.1），剩余 9% 判定翻转主要是
  贴着阈值的样本在抖动。绝对数字没有意义，只看敏感度的对比。需要在真实数据上用
  `payload_surface_stats.py` 确认偏差、重训后用 perturb_test 的 casing 族复测。
